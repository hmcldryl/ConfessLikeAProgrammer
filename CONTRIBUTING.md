# Contributing

Thanks for wanting to help out! Here's how.

## Just want to use it?

You don't need to contribute anything. Fork the project and follow the guide in the [README](README.md).

## Found a bug or have an idea?

[Open an issue](https://github.com/hmcldryl/ConfessLikeAProgrammer/issues/new) and tell me:

- What happened (or what you'd like to see)
- What you expected to happen
- Your browser and device, if it's a bug

## Want to make a change?

1. Fork the repo.
2. Make your changes in a new branch.
3. Open `index.html` in your browser and make sure everything still works (`run code`, `yes`, `no`, `cls`, `help`).
4. Open a pull request and explain what you changed and why.

## A few things to keep in mind

- Keep it simple. No frameworks or build tools, just HTML, CSS and JavaScript.
- Don't put your own names or message in a pull request. Keep the placeholders in `script.js`.
- Keep the guide in the README easy to follow for non-technical people.
